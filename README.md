## Projects
- **Color Palette** — 4 colors defined with CSS variables
- **Button** — icon added with `::before`

## Technologies

- CSS3 (Variables, Pseudo-elements)

## Features
- CSS custom properties (`:root`)
- Reusable color palette
- Pseudo-elements (`::before`, `::after`)
- Position absolute for badge
